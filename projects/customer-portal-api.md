# Customer Portal API

**Client:** RetailCo  
**Status:** Active Development  
**Tech Stack:** Symfony 7.1, API Platform 3.2, PostgreSQL  
**Team:** Indy (backend), Sarah (frontend), Mike (PM)

## Project Overview

Building a customer portal API for RetailCo that allows their customers to view orders, track shipments, and manage their account information. The API will be consumed by both a web frontend and a mobile app.

## Current Phase

Implementing core features: authentication, order history, shipment tracking.

## Key Technical Decisions

- Using API Platform for rapid API development
- JWT authentication with refresh tokens
- Implementing CQRS pattern for complex order queries
- PostgreSQL for data storage with read replicas for reporting

## My Responsibilities

- Design and implement API endpoints
- Database schema design
- Integration with RetailCo's existing order management system
- API documentation
