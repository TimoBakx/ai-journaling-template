# Internal Tools Modernization

**Status:** Planning/Early Development  
**Tech Stack:** Symfony 7.1, Symfony UX, PostgreSQL  
**Team:** Indy (lead developer), Co (junior developer)

## Project Overview

Modernizing TechCorp's internal tools suite - currently a collection of old PHP scripts and outdated applications. Goal is to consolidate into a modern Symfony application with a consistent UI and better maintainability.

## Current Phase

Planning phase - identifying which tools to migrate first, designing the architecture.

## Key Technical Decisions

- Monolithic Symfony app with modular structure (one bundle per tool)
- Symfony UX for interactive frontend components
- Shared authentication system across all tools
- Gradual migration - old tools stay running until new versions are ready

## My Responsibilities

- Architecture design
- Leading the development
- Mentoring Co (junior developer)
- Coordinating with internal stakeholders

## Challenges

- Balancing this project with client work (Customer Portal API)
- Understanding requirements from various internal teams
- Keeping scope manageable
