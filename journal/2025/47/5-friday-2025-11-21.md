## 📝 Daily Events

### ([Internal Tools](../../projects/internal-tools.md)) Helping Co with Authentication

Started the day by helping Co set up the authentication system for Internal Tools. We're using Symfony's Security component with a custom user provider that authenticates against our existing employee database.

Walked Co through the security.yaml configuration and explained how the different parts work together - the firewall, the user provider, the password hasher. Co had good questions about why we're using a custom user provider instead of Doctrine's entity user provider.

This was a good teaching moment. Explained that while Doctrine's user provider is simpler, we need the custom provider because our employee data is in a legacy database with a different structure. This led to a broader discussion about when to use framework defaults vs custom solutions.

Co implemented the basic authentication and got it working. He's learning fast.

### ([Customer Portal API](../../projects/customer-portal-api.md)) Finishing the Caching Implementation

Completed the cache invalidation logic for the order history caching. Used Symfony's cache tags to make invalidation easier - when a new order is created or updated, we invalidate the cache for that specific customer.

Tested thoroughly on my local environment. The caching is working well - order history requests are now sub-100ms instead of 2-3 seconds for customers with many orders. That's a significant improvement.

Deployed to staging and verified everything works correctly. The performance improvement is noticeable even on staging data.
